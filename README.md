#  Proyecto Portafolio y Galería Web

Sitio web desarrollado como proyecto académico para la materia **Desarrollo de Aplicaciones Web**, cuyo objetivo es presentar un **portafolio personal** y una **galería de imágenes** mediante una interfaz moderna, responsive y fácil de navegar.

---

##  Descripción del Proyecto

Este sitio web permite:
- Mostrar información general del proyecto
- Presentar un **portafolio** con secciones organizadas
- Visualizar una **galería de imágenes**
- Navegar entre secciones usando **React Router**
- Utilizar un diseño moderno con **Tailwind CSS**

---

##  Tecnologías Utilizadas

- React 18
- Vite
- Tailwind CSS
- React Router DOM
- TypeScript

---

##  Instalación y Ejecución

1. Clonar el repositorio:
```bash
git clone https://github.com/cquispe21/spa-uees
```

2. Instalar dependencias:
```bash
npm install
```

3. Ejecutar el proyecto:
```bash
npm run dev
```

4. Abrir en el navegador:
```
http://localhost:5173
```
